# DestiFly Travels — Business Portal

A lightweight, single-file browser portal for DestiFly Travels.

## Features
- Dashboard overview and quick actions
- Customer records and search
- Booking creation, status tracking, and deletion
- Umrah visa/package rate reference
- Air-ticket and transport records
- Hotel list management
- Income/expense ledger
- Marketing contact details and copyable promo text
- JSON backup/restore and CSV exports
- Responsive desktop and mobile layout

## Open the portal
After GitHub Pages is enabled and deployment succeeds, the portal should be available at:

https://destifly.github.io/desti-business-portal/

The source file is [index.html](./index.html).

## Deployment
The repository includes a GitHub Actions Pages workflow. In GitHub, open **Settings → Pages** and choose **GitHub Actions** as the build/deployment source if it is not already selected. Then check the **Actions** tab for a successful Pages deployment.
